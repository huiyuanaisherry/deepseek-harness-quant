# 真实数据接入需求与验收记录

状态：执行中。更新日期：2026-10-25。

## 用户目标与边界

在用户自己的 Windows / WSL 实例使用已配置的 Tushare Pro 兼容中转，先验证少量股票，再推进现有选股流程。项目需求、决策、进度和验收证据保存在本项目 docs 并随 fork 同步，不登记到 Mac 的外部知识库。

- 用户指定：紫光股份（000938.SZ）、浪潮信息（000977.SZ）。
- 补充测试样本：中兴通讯（000063.SZ）、中科曙光（603019.SH）、工业富联（601138.SH）、海光信息（688041.SH）。名称和代码应以供应商基本信息再次核对。这是技术验收样本，不是推荐买入或全市场排名。
- 初始范围：近两年交易日历、股票信息、日线、复权因子、每日基本指标、财务指标。串行小规模查询，拒绝无界全市场任务。
- 独立目录保存真实数据，保留 data/demo；不自动更改网页数据源、启动定时任务、全市场下载或交易。
- Token 只保留在服务端现有配置，不进入代码、Git、文档、URL、普通日志。真实行情不得上传 GitHub。

## 验收顺序

1. 统一配置验证与真实采集的 HTTP 请求路径、代理、超时和目的地检查。
2. 样本数据落库；校验字段、交易日期、重复键、价格、成交量/成交额单位、复权因子完整性、最新日期和财务披露时间。重复写入后行数和值保持一致。
3. 从独立库读回，尝试现有筛选规则；缺失财务、历史长度、全市场分位或外部因子时明确标记不可验收，禁止补造数据、评分或收益。
4. 写入本轮验收范围与实际结果。小样本通过后才扩大覆盖；生产网页切换和调度另行记录。
